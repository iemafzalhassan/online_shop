# Online Shop - Hackathon Phase 1 Solution

---


## Overview

The **Online Shop** project is a demo e-commerce application designed for Hackathon Phase 1. It serves as a platform to showcase best practices in code quality, development workflows, and system design with a focus on:

- **Git & GitHub**
- **Linux**
- **Docker**
---

## Task Descriptions & Implementations

For this hackathon phase, your work will center around the following tasks:

### Git & GitHub

- **Repository Management:**
Fork and Clone: Forked and cloned the repository to work on the project.
Branches: Created new branch to work on different features, keeping the main branch clean and stable.
Commit History: Made sure commits were clear and well-documented.
- **Collaboration Practices:** 
Descriptive Commits: Each commit was written with a clear message to describe what we worked on.
Pull Requests: Created pull requests for changes.
- **Workflow Optimization:** 
Tried to identify areas where the Git workflow could be improved and noted some suggestions for future updates to make things smoother.

### Linux

- **Command Line Proficiency:**
Used the Linux command line to manage files, run system scripts, and set up environment configurations for the project.
Tested the system to make sure everything was running smoothly.
- **System Administration:**
Looked into how the application handled file management, permissions, and process monitoring on Linux.
- **Documentation:**  Documentai=tion is created.

### Docker

- **Containerization Principles:**
Created a Docker file and created containers and images.
- **Conceptual Improvements:**
Tried to implement Docker integration and created a single and two tier architecture. 
- **Code Readiness:**
Checked the code structure was ready for Docker, so it could be deployed on a cloud platform like AWS.
