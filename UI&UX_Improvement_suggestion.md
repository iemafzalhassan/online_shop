## UI Feature Suggestions

### 1️⃣ General Design Layout

1. Modern and clean UI
   - overall design should be improve with spacing between letters and images and
   - improve color scheme from dark to using a combination like this one eg. #F8F3D9 , #EBE5C2 , #B9B28A, #504B38
2. Better Logo Design and Brandname
3. smart searh with Auto suggestions while searching a product. eg:amazon, myntra,flipkart etc.

   - Personalized Recommendations for the product like frequent bought by customer or trending

4. Rating and Reviews sections.
5. Loading Skeleton or spinner
   - Improve the loader like make it with smoother animations

### 2️⃣ Navigation and layout

1. Sticky header and navbar
   - keep navigation bar sticky while scrolling for a better user experience
2. Breadcrumbs navigation
   - Show user path wile using website eg: Home > Cart > Product_name
3. Menu for category
   - create a Big Category listing menu for products.
4. Filters for different products

### 3️⃣ Shopping Cart and checkout

1. Cart Dropdown

   - Display a Preview of the cart when hover over the cart button
   - cart preview is shown when a product is selected.

2. Guest Checkout

   - Let Users buy without login the website by just providing the shipping address and contact details while checkout.

3. Payment options
   - Provide multiple payment options like UPI, online banking, credit card

### 4️⃣ Multiple Devices Responsiveness and performance

1. Mobile Friendly layout

   - Application should be perfect for mobile friendly
   - resize the complete application for different mobile devices.

2. Faster Loading time

   - Resize the product images to load at perfect time avoid lazy loading content and minify the assests.
